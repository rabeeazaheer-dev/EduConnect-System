# EduConnect-System 🎓

A robust, Desktop-based School Management System developed using **C# .NET** and **SQL Server**. This application simplifies administrative operations, record keeping, and database interactions through structured CRUD workflows.

---

## ✨ Key Features
- **Student & Staff Management:** Full CRUD operations (Create, Read, Update, Delete) for student/staff profiles.
- **Database Integration:** Centralized data management powered by Microsoft SQL Server.
- **User Interface:** Clean, user-friendly Windows Forms GUI for seamless workflow navigation.
- **Data Persistence:** Relational database architecture ensuring data integrity and fast queries.

---

## 🛠️ Tech Stack & Tools
- **Language:** C#
- **Framework:** .NET Framework / WinForms
- **Database:** Microsoft SQL Server
- **IDE:** Visual Studio
